# Imunity GPT 업무자동화 강의 자료

GPT와 업무 도구를 연결해 간단한 자동화를 만들어보는 실습 자료입니다.

## 1회차 실습 데이터

[간단한 월별 매출 데이터 다운로드](https://github.com/Ponti4/imunity-gpt-work-automation-class/releases/latest/download/monthly-sales-data.xlsx)

### 실습 요청문

> 첨부한 매출 데이터를 Spreadsheet로 옮겨 정리해 주세요.
>
> - 월별 총매출을 계산해 주세요.
> - 매출이 가장 높은 달을 표시해 주세요.
> - 월별 매출을 막대그래프로 만들어 주세요.

파일 다운로드 후 ChatGPT에 첨부하고 위 요청문을 입력하세요.
